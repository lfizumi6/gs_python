1.	Descrição da Solução Proposta     
O projeto SOLARIA foi desenvolvido com o objetivo de monitorar e analisar dados relacionados ao clima espacial, utilizando conceitos de programação em Python para criar uma solução funcional voltada à prevenção de impactos causados por tempestades solares. O problema abordado pela equipe está relacionado aos riscos que explosões solares podem causar em satélites, sistemas de telecomunicação e redes elétricas terrestres.     
A solução computacional criada simula uma plataforma de inteligência preditiva conectada a um microssatélite responsável por coletar dados de radiação solar e temperatura. O sistema permite armazenar leituras em listas, realizar análises automáticas e emitir alertas quando os níveis de radiação ultrapassam limites considerados seguros.     
O principal objetivo do sistema é antecipar possíveis eventos geomagnéticos extremos e auxiliar setores críticos, como energia e telecomunicações, oferecendo ações preventivas para reduzir danos operacionais e econômicos.     
Entre as funcionalidades implementadas estão: ingestão de dados do satélite, validação de entradas do usuário, triagem automática de alertas, simulação de cenários históricos baseados no Evento de Carrington de 1859 e emissão de relatórios de mitigação para diferentes setores estratégicos.     
O sistema foi desenvolvido utilizando estruturas condicionais, estruturas de repetição, funções com parâmetros e retorno, listas e tratamento de exceções, aplicando os conceitos estudados durante o primeiro semestre da disciplina de Computational Thinking With Python.     
Além disso, o projeto apresenta um menu interativo via terminal, tornando a navegação intuitiva e melhorando a experiência do usuário por meio de mensagens organizadas e validações de entrada.
